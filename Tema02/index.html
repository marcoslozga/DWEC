Navegadores y motores

Un navegador utiliza un motor de renderizado para convertir HTML y CSS en la página que vemos. También utiliza un motor de JavaScript para ejecutar el código de la página. Chrome, Edge y Opera usan Chromium y Blink, por lo que comparten muchas características. Firefox usa Gecko y SpiderMonkey. Safari usa WebKit y JavaScriptCore. Por eso una página puede comportarse de forma diferente según el navegador. Para desarrollar una web es importante probarla en varios navegadores.

Popover API

La API Popover no es compatible con algunas versiones antiguas de los navegadores. Por eso, antes de utilizar una característica nueva, es importante comprobar su compatibilidad.
