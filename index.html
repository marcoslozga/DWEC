Navegadores y motores

Un navegador utiliza un motor de renderizado para convertir HTML y CSS en la página que vemos. También utiliza un motor de JavaScript para ejecutar el código de la página. Chrome, Edge y Opera usan Chromium y el motor de renderizado Blink, por lo que comparten muchas características. Firefox usa Gecko y su motor de JavaScript SpiderMonkey. Safari usa WebKit y JavaScriptCore, por lo que puede tener diferencias con los navegadores basados en Chromium. Para desarrollar una web conviene probarla en más de un motor para detectar posibles problemas de compatibilidad.

Ejemplo real de compatibilidad

Popover API

Según Can I Use, la API Popover no está disponible en Chrome 115 y anteriores, Firefox 124 y anteriores y Safari 16.6 y anteriores. En versiones posteriores sí aparece como compatible. Esto demuestra que una característica nueva puede necesitar comprobación antes de utilizarse en una web.
