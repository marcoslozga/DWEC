## Reflexión

**Borrador para revisar y redactar con mis palabras:** `for` suele venir bien cuando sé de antemano cuántas vueltas necesito. `while` comprueba la condición antes de cada vuelta, por eso con 0 no entra. `do...while` comprueba la condición al final y ejecuta el bloque al menos una vez. En esta práctica, con el valor 0, `for` y `while` muestran un total de cero; `do...while` muestra una repetición. Si necesito que el bloque se ejecute como mínimo una vez, elegiría `do...while`; para contar repeticiones conocidas, usaría `for`; y para continuar hasta que cambie una condición, `while`.
